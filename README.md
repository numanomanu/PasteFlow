# PasteFlow ⚡️

> **Clipy よりも圧倒的に洗練された、キーボードファーストの macOS クリップボードマネージャー**

`Cmd + Shift + V` で呼び出し、検索・選択・貼り付けまでキーボードだけで完結するモダンなクリップボードアプリです。  
Clipy の「1〜30」「31〜60」といった使いにくい階層フォルダ構造を完全に排除し、Spotlight / Raycast スタイルのフラットかつインクリメンタル検索可能な 2 ペイン UI を採用しています。

---

## ✨ 主な特長

### 1. フォルダ構造のないフラットな 2 ペイン UI
- **フォルダをたどるストレスゼロ**: 直近の履歴がフラットに時系列で並びます。
- **インクリメンタル検索**: ポップアップが開いた瞬間にキーボードを叩くだけで、過去の履歴をリアルタイムに絞り込み検索。
- **リッチプレビュー**: 右側ペインでテキスト全文、行数・文字数、画像解像度、カラーパレット、URL ドメインなどを一目で確認。

### 2. キーボードファーストの超高速ペースト
- `⌘ + ⇧ + V`: どこからでも一瞬で呼び出し。
- `↑` / `↓`: 履歴を選択。
- `Tab` / `⇧ + Tab`: カテゴリフィルタ（すべて ➜ ピン留め ➜ テキスト ➜ リンク ➜ 画像 ➜ カラー）を切り替え。
- `Enter (↵)`: 選択したアイテムを直前のアプリに自動ペースト。
- `⌘ + 1` 〜 `⌘ + 9`: 上位アイテムを 1 ストロークで即座にペースト。
- `⌘ + P`: よく使うスニペットをピン留め（自動削除されず一番上に固定）。
- `⌘ + C`: クリップボードにコピーのみ（貼り付けない）。
- `⌘ + ⌫`: 不要な履歴を削除。
- `Esc`: ポップアップを閉じる。

### 3. スマートなコンテンツ認識
- **カラーコード認識**: `#007AFF` や `rgb(255, 0, 128)` などのカラーコードを検知すると、右ペインにカラーチップと各カラーフォーマットを表示。
- **Web リンク認識**: URL を検知し、クリックでブラウザを開くボタンを表示。
- **画像クリップボード**: コピーした画像をサムネイル・原寸比でプレビュー＆ペースト可能。
- **プライバシー保護**: 1Password やパスワードマネージャーの機密データ（Concealed / AutoGenerated / Transient）は自動で除外。

### 4. macOS ネイティブ & 軽量
- SwiftUI + AppKit による完全なネイティブ実装。
- すりガラス（Frosted Glass）によるモダンなデザイン（ダーク / ライトモード自動追従）。
- メニューバー常駐ユーティリティ（Dock アイコンを出さず常駐）。

## 🚀 起動方法

### ターミナルから起動する場合
```bash
open PasteFlow.app
```

### アプリケーションフォルダに配置する場合
```bash
cp -R PasteFlow.app /Applications/
```

### 再ビルドする場合
```bash
./build_app.sh
```

## ⚙️ 初回起動時のアクセシビリティ権限について

PasteFlow は、履歴を選択して `Enter` または `⌘1~9` を押した際に、**直前に作業していたアプリに自動で `Cmd + V` を送信して貼り付け** を行います。

この自動キーストローク送信を有効にするため、初回のみ以下の設定を行ってください：
1. メニューバーの PasteFlow アイコンまたは歯車アイコンから「設定」を開きます。
2. 「アクセシビリティ権限」の「権限を設定...」をクリックします。
3. macOS の「システム設定 > プライバシーとセキュリティ > アクセシビリティ」で **PasteFlow** を許可してください。

*(※権限が許可されていない場合でも、クリップボードへのコピーは完了しているため、手動で Cmd + V で貼り付けることができます)*

## ⌨️ ショートカットキー一覧

| キー | 動作 |
| :--- | :--- |
| **`⌘ + ⇧ + V`** | PasteFlow ポップアップを開く / 閉じる |
| **`↑` / `↓`** | 履歴を選択 |
| **`Tab` / `⇧ + Tab`** | カテゴリフィルタを順に切り替え |
| **`Enter (↵)`** | 選択した項目を直前のアプリに自動ペースト |
| **`⌘ + 1` 〜 `⌘ + 9`** | 上位 1〜9 件の項目を即座にペースト |
| **`⌘ + P`** | 選択項目のピン留め / ピン留め解除 |
| **`⌘ + C`** | クリップボードにコピー (ペーストせず閉じる) |
| **`⌘ + ⌫`** | 選択項目を履歴から削除 |
| **`Esc`** | ポップアップを閉じる |
| **文字入力** | 履歴のリアルタイム・インクリメンタル検索 |
